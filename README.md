# proect1 — админ-бхоп для своей копии MM2

Бхоп в стиле CS/Source с полным меню настроек. Скрипт получают **только админы**:
сервер копирует его им в `PlayerGui`, у обычных игроков кода нет вообще.

## Установка (без Rojo)

1. В Studio создай **Script** в `ServerScriptService`, назови `AdminBhop`, вставь
   `src/ServerScriptService/AdminBhop.server.lua`.
2. Создай **LocalScript** в `ServerStorage`, назови строго `AdminBhopClient`, вставь
   `src/ServerStorage/AdminBhopClient.client.lua`.
3. В начале `AdminBhop` впиши свой UserId в таблицу `ADMINS`
   (или укажи группу в `ADMIN_GROUP`).
4. Чтобы работало сохранение: Game Settings → Security → **Enable Studio Access to API Services**.

С Rojo: `rojo serve` (конфиг `default.project.json` уже есть).

## Управление

| Клавиша | Действие |
|---|---|
| `RightShift` | открыть/закрыть меню |
| `B` | включить/выключить бхоп |
| `Space` (держать) | автопрыжок |
| `A`/`D` + мышь | стрейфы для набора скорости |

Обе клавиши меняются прямо в меню. На телефоне слева появляется кнопка `BH`.

## Настройки

- **Пресеты:** Легит / CS:S / Безумие.
- **Основное:** автопрыжок, сохранение скорости, окно перфект-хопа, сила прыжка, буст за прыжок (%), макс. скорость.
- **Стрейфы:** air-strafe, авто-стрейф (скорость набирается одной мышью), air accelerate, air speed cap.
- **Земля:** ускорение, трение, stop speed, свой WalkSpeed.
- **Визуал:** спидометр (скорость / макс / прыжки), FOV от скорости, уведомления.
- **Профиль:** сохранение в DataStore (подгружается при входе) и сброс.

## Невидимость для игроков

Другие игроки ничего не видят:
- скрипт, меню и remote лежат в **твоём** `PlayerGui`, а он реплицируется только тебе;
- никаких атрибутов, объектов в `ReplicatedStorage` или `workspace` не создаётся;
- уведомления, спидометр и FOV видны только тебе.

Со стороны видно только то, как двигается твой персонаж.

## Античит

Если в твоей MM2 есть серверная проверка скорости, пропусти админа (проверка живёт только на сервере):

```lua
local adminCheck = game.ServerStorage:WaitForChild("AdminBhopCheck")
if adminCheck:Invoke(player) then return end
```
