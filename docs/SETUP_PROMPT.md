# Промт для ассистента в Visual Studio / VS Code

Вставьте текст ниже в чат ассистента (Copilot Agent, Claude Code, Cursor и т. п.). Ассистент должен иметь доступ к терминалу
(режим Agent). Если доступа нет, он выдаст команды, а вы запустите их сами.

```
Ты помогаешь мне развернуть проект MM2 Hub на моём Windows-ПК. Выполни шаги по порядку, после каждого проверяй результат
и сообщай мне, что получилось и что нет. Ничего не придумывай: если шаг не удался, покажи точную ошибку.

ПРАВИЛА
- Не изменяй и не удаляй файлы исходников проекта (src, tests, tools, server, loader, docs).
- Папка .license содержит секрет подписи ключей. Никогда не показывай её содержимое, не коммить её, не загружай её никуда.
- Не отправляй мои данные в интернет, кроме скачивания: Python, репозитория с GitHub и программы cloudflared от Cloudflare.
- Если для шага нужны права администратора или моё подтверждение, остановись и спроси.

ШАГИ
1. Проверь, установлен ли Python 3 (команды `python --version` или `py -3 --version`). Если нет, установи:
   `winget install -e --id Python.Python.3.12` и попроси меня перезапустить терминал, затем проверь снова.
2. Проверь Git (`git --version`). Если нет, установи: `winget install -e --id Git.Git`.
3. Скачай проект в папку, которую я укажу (по умолчанию C:\MM2Hub):
   `git clone -b claude/youthful-cray-l6ypwp https://github.com/TETERGitHub/proect1.git C:\MM2Hub`
   Если репозиторий приватный и git просит вход, попроси меня авторизоваться и не пытайся обойти это.
4. Перейди в папку проекта и запусти проверку сборки: `python tools/build.py`. Должен появиться файл dist\MM2Hub.lua.
   Сообщи мне его размер.
5. (Необязательно, для проверки тестов.) Скачай Luau CLI для Windows со страницы
   https://github.com/luau-lang/luau/releases/latest (файл luau-windows.zip), распакуй в C:\MM2Hub\tools\bin и выполни
   `python tools/run_tests.py C:\MM2Hub\tools\bin\luau.exe`. Сообщи мне итоговую строку TOTAL ... PASSED ... FAILED ...
   (ожидается 323 PASSED, 0 FAILED). Не заявляй, что тесты прошли, если ты их не запускал.
6. Запусти сервер: `python tools/control.py serve` (для владельца есть окно PANEL_WINDOWS.bat — там то же кнопкой «Запустить сервер»).
   Программа сама создаст секрет ключей, соберёт хаб, запустит сервер, скачает cloudflared, получит адрес https://….trycloudflare.com
   и соберёт dist\Loader.lua под этот адрес. Дождись строки READY и покажи мне только публичный адрес и путь к Loader.lua.
7. В том же меню выбери пункт 2 и создай тестовый ключ на 1 день (в поле «Дни» впиши 1, остальные оставь пустыми).
   Покажи мне ключ. Он нужен мне для проверки.
8. Объясни мне, что делать дальше:
   - Loader.lua это единственный файл, который нужно раздавать пользователям;
   - окно с программой должно оставаться открытым, пока кто-то пользуется хабом (при закрытии сервер остановится);
   - адрес быстрого туннеля меняется при каждом запуске, поэтому после перезапуска нужно заново раздать новый Loader.lua;
   - постоянный адрес требует своего домена или VPS (пункт «Постоянный хостинг» в docs/SERVER.md).
9. В конце выведи краткий отчёт: что установлено, что запущено, какие файлы созданы, какие шаги не удались и почему.

ЧЕГО НЕ ДЕЛАТЬ
- Не запускай ничего в игре Roblox и не пытайся проверять работу хаба в игре: у тебя нет доступа к клиенту.
- Не меняй настройки безопасности Windows и брандмауэра без моего разрешения.
```
