Перед этим один раз: Sketchfab → Settings → Password & API → скопировать API token; в терминале `setx SKETCHFAB_TOKEN "токен"`,
перезапустить VS. Токен никому не отправлять.

Найди, покажи мне на выбор, скачай и подготовь 3D-модели со Sketchfab для моего Roblox-хаба (только локальная косметика на моём клиенте).
Рабочая папка: `C:\Users\User\mm2_models\`. Blender 5.2.2 установлен.

## Что нужно (18 моделей)
- **Оружие мардера (ножи) — 5:** например катана, керамбит, мачете/тесак, футуристический/энергетический нож, кинжал. Длина ~3–4 studs.
- **Оружие шерифа (пистолеты) — 5:** например AWP (снайперка), револьвер, современный пистолет, бластер, дробовик/обрез. Пистолет ~2.8, снайперка ~6 studs.
- **Персонажи — 8:** гуманоиды (человекоподобные, две руки, две ноги), в т.ч. Tung Tung Sahur; остальные — популярные/мемные стилизованные персонажи.

## Правила (обязательно)
1. Токен — только из переменной окружения `SKETCHFAB_TOKEN`. Не печатай его, не пиши в файлы, логи и скрипты.
2. Ищи через API: `GET https://api.sketchfab.com/v3/search?type=models&downloadable=true&q=<запрос>&sort_by=-likeCount`.
   Бери только модели с `isDownloadable = true` и лицензией **CC BY, CC BY-SA или CC0** (проверь `GET /v3/models/{uid}` → `license`).
   Никаких Standard/Editorial, NoDerivatives (ND), платных и с запретом скачивания.
3. Предпочитай реалистичные/качественные модели с текстурами; до ~50 000 треугольников в оригинале (дальше я упрощу).
   Никаких «кубических» и low-poly-блочных моделей.
4. Ничего не запускай из скачанных файлов (скрипты, exe). Только модели и текстуры.

## Шаг 1 — выбор (СТОП, жди меня)
Для каждой из 18 позиций найди 3 кандидата и сделай `choices.html`: картинка-превью (`thumbnails` из API), название, автор, лицензия,
число треугольников, ссылка. Покажи мне и **жди, пока я выберу** по одному на позицию.

## Шаг 2 — скачать
`GET https://api.sketchfab.com/v3/models/{uid}/download` с заголовком `Authorization: Token <токен>`; качай `glb` (или `gltf` zip) сразу —
ссылка живёт недолго. Сохрани в `input\<имя>\`. Запиши в `CREDITS.txt`: имя файла, название, автор, ссылка, лицензия.

## Шаг 3 — подготовить в Blender (скриптом `prepare.py`, чтобы можно было повторить)
- Импортируй, примени трансформации, удали камеры/свет/пол/подставки, оставь одну модель.
- **Оружие и ножи:** ствол/остриё смотрит в **−Z**, верх **+Y**, 1 unit = 1 stud (длины выше), **origin в центре рукояти (хват)**.
  До 8 000 треугольников (Decimate, следи, чтобы силуэт не ломался), не больше 4 материалов, текстуры ≤ 1024×1024.
- **Персонажи:** смотрят в **−Z**, высота ~5.5 studs, origin в середине таза, ступни на y = −3.
  РАЗРЕЖЬ меш на части по костям Roblox R15 (каждая часть — отдельный объект с точным именем):
  `Head, UpperTorso, LowerTorso, LeftUpperArm, LeftLowerArm, LeftHand, RightUpperArm, RightLowerArm, RightHand, LeftUpperLeg, LeftLowerLeg, LeftFoot, RightUpperLeg, RightLowerLeg, RightFoot`.
  Если модель с арматурой — дели по весам костей; если без — по положению (голова, торс, руки, ноги). Предмет в руке — `RightHand_<имя>`.
  До 15 000 треугольников на персонажа.
- Экспорт: glTF Binary `.glb`, Apply Modifiers, +Y Up. Имена: `knife_<имя>.glb`, `gun_<имя>.glb`, `char_<имя>.glb` (латиница, цифры, `_`, до 20 символов).

## Шаг 4 — проверка и сдача

- `REPORT.md`: таблица — имя, источник, автор, лицензия, треугольники, размер в studs, материалы, что изменено, известные недостатки.
- Не пиши «готово», если не проверил на превью.
- Сложи в `deliver\` (`*.glb`, `preview_*.png`, `CREDITS.txt`, `REPORT.md`, `prepare.py`) и упакуй в `deliver.zip`. Я отправлю архив в другой чат.
